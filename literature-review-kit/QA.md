## 実装検証

| 検証 | 結果 |
|---|---|
| 標準ライブラリの自動テスト | 19件PASS |
| 別テーマの独立利用試験 | 合成の材料／土壌テーマで初期化、検索・全ヒット取込、指示再取込、重み変更、更新、再開、audit/build/nextを確認 |

自動テストは、失敗を0件へ置き換える誤り、順位の抜け、ページ再取得、同一順位の論文変動、概数からの残件確定、保存と読了の混同、根拠不足での抽出完了、事後登録の既知論文試験、ユーザー指示の重複等を対象とする。

独立試験では、`request_id` を省略した同一JSONの再取込でタスクが重複する問題を発見・修正した。再取込しても同じIDと完了状態が保持されることを再確認した。合成データは実調査へ混ぜていない。

2026-11-11追記：論文・検索ヒット・次の候補・利用者指示・下書き一覧に判定対象・クラス欄を追加。67論文のlabels根拠を値・確認状態・ID付きで表示し、未抽出候補は未確認とする。`verify_dashboard.py` でこの表示用データと全根拠行の一致を確認した。既存19テストとJS構文はPASS。

再実行（このフォルダから）：

```powershell
$env:PYTHONUTF8='1'
python -m unittest discover -s tests -v
python scripts/review.py audit --project examples/tool-wear-review
python scripts/review.py build --project examples/tool-wear-review
python scripts/verify_dashboard.py --project examples/tool-wear-review
```

最後の静的検査にはNode.jsが必要。`--node` で実行ファイルを指定できる。調査台帳の操作とHTML生成はPython標準ライブラリだけで動く。

台帳338行は独立した詳細採用研究338本を意味しない。取得した全ヒットと比較表を結び、DOI/arXiv/出版社URLの一致で統合したが、題名のみの一致や未同定を残している。旧比較の採用50本は変更していない。

過去の引用調査全体、Web横断検索全体、広域の商用・学術比較は移行対象外である。今回の新規検索・ダウンロード・本文精読は行っていない。`project.json` の `migration_scope` に境界を明記した。

移行後の監査は **WARN、構造エラー0、注意22**。21実行の検索式意味検証が不完全で、1論文は基準年より後の巻号年を含む。警告を消すために確認済みへ変更していない。必須式の未実施・意味未確認は28式で、単なる未実行3式とは異なる。

予定範囲の残順位、未選別、引用追跡、抽出不足が画面に残る。既定の取得目標100等は調整可能な今回の計画であり、過去にその量の探索を完了したという記録ではない。

## 未実装・限界

- DB横断クローラ、自動購入、サブスクリプション認証、PDFの自動精読機能は含まない。AIエージェントが利用できる正規の検索・閲覧手段を使い、実施結果を記録する。
- HTMLの指示JSONは下書き。`import-requests` で取り込み、担当エージェントが実施・根拠を登録して初めて完了になる。
- スコア・候補率は読む順番の補助。文献品質、未知集合の発見確率、世界全体の網羅率ではない。
- 台帳に計画していない未知の研究領域は自動検出できない。検索計画自体のレビューと別経路の追加探索を継続する。
- 設定・台帳・履歴は1担当者ずつ更新する。複数人同時編集のデータベース機能は持たない。
- 保存PDFは同梱しない。別環境では参照ファイルがなくても出典URLから確認し、保存状態を再点検する。

静的検査の機械可読結果は [html_validation.json](examples/tool-wear-review/outputs/html_validation.json)、調査台帳の監査は [audit.json](examples/tool-wear-review/outputs/audit.json) に保存する。
