# P0119 HEIDENHAIN VT122 + Visual Tool Check 1.6

機内カメラの工具パノラマ画像からAIでエンドミル逃げ面摩耗を自動測定。

| 項目 | 確認内容 |
|---|---|
| 対象工具 | エンドミル（自動VB明示）。ドリルは摩耗測定対応表あり、自動化範囲未確認。ボール/トロイドは画像・工具測定のみ表記 |
| 対象加工法 | エンドミル加工（摩耗測定）、他は撮影/寸法測定対応と区別 |
| 使用データ | 工具全周パノラマ画像・刃先画像 |
| 判定可能な状態・指標 | 逃げ面摩耗幅平均/最大、経時摩耗、警告/使用停止閾値、CSV出力 |
| 確認済み実装モデル | AIによる画像ベース逃げ面摩耗幅測定（固有モデル名未確認） |
| モデル構造・処理フロー | 工具低速回転→全周画像→刃別AI解析→平均/最大VB→警告/工具ブロック |
| 学習方式 | 社内の大量画像で事前学習（教師付け詳細未確認） |
| 判定精度・性能 | AI摩耗測定の標準精度±20 µm；摩耗測定分解能5 µmは別指標 |
| 評価指標と評価条件 | 2025日本語公式製品情報p.7標準測定精度。比較対象・試験工具/分割は未記載。p.5は分解能で精度と異なる |
| 処理時間・リアルタイム性 | 撮影から数秒（メーカー記載、ハード/評価条件未記載） |
| 導入に必要な設備・環境 | VT122カメラ、VTC1.6自動摩耗オプション、対応CNCサイクル・PC、圧縮空気/清掃 |
| 技術的制約 | AI自動化はエンドミルと明記。ボール/トロイドの摩耗測定表は非対応表示。ドリル欄の✓を自動AI対応へ拡張しない |
| 未確認事項 | 販売開始年、価格、市場規模、独立試験条件、固有AI構造は未確認 |

[公式日本語仕様書](https://news.heidenhain.com/fileadmin/pdf/ja/Produktinformation/PI_VT121_ID1324220_ja.pdf) p.5が測定分解能、p.7がAI標準精度と学習説明。5µmと±20µmを取り違えない。

2025-09-11はVTC1.6機能発表日。日本語資料のVT121というファイル名のみから全機能をVT121固有仕様と推定しない。本文の対応機種・オプションを選定時に再確認する。
