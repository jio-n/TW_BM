# IV001：MVREC: A General Few-shot Defect Classification Model Using Multi-View Region-Context

Shuai Lyu, Rongchen Zhang, Zeqi Ma, Fangjian Liao, Dongmei Mo, Waikeung Wong。2025、AAAI 2025。

[IV001: MVREC: A General Few-shot Defect Classification Model Using Multi-View Region-Context](https://arxiv.org/html/2412.16897)／DOI：10.1609/aaai.v39i6.32634

| 項目 | 内容 |
|---|---|
| 概要・対象 | 工業外観検査 |
| 対象製品 | テクスチャ5製品群と物体9製品群。金属ナット、ねじ、ケーブル、ボトル、カプセル、タイル、布等。 |
| モデル系統 | 対照学習VLM由来（視覚塔＋マスク） |
| 主要モデル・処理 | MVREC＋Zip-Adapter(-F)。事前学習済みAlphaCLIPがマスクと周囲文脈の多視点特徴を抽出。Zip-Aは視覚的類似度によるサポート検索、Zip-A-Fは投影・サポート特徴を微調整。推論はサポートのone-hotラベルに基づく。 |
| 入力 | 欠陥画像と既知の欠陥インスタンスマスク、ラベル付きサポート画像・マスク。画像から欠陥を自力発見する性能とは別。 |
| プロンプト | 主提案は推論時に自然言語プロンプトなし。CLIP-ZeroShot比較条件ではクラス記述をテキスト埋め込み化。 |
| 出力タスク | 欠陥インスタンス単位、製品別の単一ラベル種類分類 |
| 原語クラス | 原文Table 7の例：bottle＝broken_large, broken_small, contamination。metal_nut＝bent, color, flip, scratch。transistor＝bent_lead, cut_lead, damaged_case, misplaced。全リストはTable 7。 |
| 複合・多ラベル | 一枚に複数欠陥がある元のcombined画像をインスタンスに分割し個別にラベル付け。 |
| データ | MVTec-FS（MVTec ADの再注釈）、NEU-DET、PCB Defect Dataset、MTD、AITEX |
| 規模 | MVTec-FS 1,228欠陥画像、14製品群。種類別インスタンス数9–58。 |
| 学習・分割 | 種類ごとに50%/50%に分け、訓練側から各クラス1/3/5枚をサポート抽出、固定のテスト側をクエリ。サポートを5回抽出し平均。 |
| 学習方式 | N-way K-shot。Zip-Aは追加学習なし、Zip-A-Fは交差エントロピー＋triplet loss。 |
| 性能 | MVTec-FSのZip-A-Fは1/3/5-shotで73.7%/86.1%/89.4%。同表のテキスト0-shot比較は37.4%。 |
| 比較モデル | AlphaCLIP共通。CLIP-ZeroShot、CLIP-KNN、CLIP-ProtoNet、CLIP-Adapter、CLIP-LinearProb、Tip-Adapter(-F)。 |
| 未知条件への評価 | 他の4工業データセットでもデータセット内でサポートを再抽出して評価。サポートなしの工場外移植は未確認。 |
| 制約 | マスク付き欠陥インスタンスが前提。製品群をまたぐ単一46クラス分類のスコアとしては扱えない。 |
| 確認状態 | 全文確認 |
