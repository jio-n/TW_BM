# IM004：Multimodal RAG-driven Anomaly Detection and Classification in Laser Powder Bed Fusion using Large Language Models

Kiarash Naghavi Khanghah; Zhiling Chen; Lela Romeo; Qian Yang; Rajiv Malhotra; Farhad Imani; Hongyi Xu。2025、ASME 51st DAC / IDETC-CIE 2025。

[IM004: Multimodal RAG-driven Anomaly Detection and Classification in Laser Powder Bed Fusion using Large Language Models](https://doi.org/10.1115/DETC2025-168615)／DOI：10.1115/DETC2025-168615

| 項目 | 内容 |
|---|---|
| 概要・対象 | 金属積層造形／LPBF |
| 対象製品 | 粉末床の層画像（AddUp FormUp 350、EOS M290、4材料条件） |
| モデル系統 | VLM（MLLM） |
| 主要モデル・処理 | RAG＋GPT-4o-mini／Qwen2-VL-2B。ColPali画像検索、text-embedding-ada-002文献検索。 |
| 入力 | 溶融後・粉末塗布後の実可視画像、科学文献由来の欠陥参照画像・記述。ORNLのIR等は保有されるが当該モデルの評価入力は可視。 |
| プロンプト | 名前付き欠陥ごとに文献根拠を提示し有無を回答、各対象を3回試行。別出力段階で各種類を0/1に整形。 |
| 出力タスク | 粉末床の名前付き欠陥の多ラベル分類（種類ごとの有無、単一の正常／異常検出とは別） |
| 原語クラス | §3: Recoater Hopping, Recoater Streaking, Incomplete Spreading, Swelling, Debris, Super-Elevation, Soot, Excessive Melting, Localized Bright Spot, Spatter on Powder, Mounding Powder, Localized Dark Regions, Misprint。付録表ではEdge Swelling、Crashing、Stripe Boundaryの表記も使用。 |
| 複合・多ラベル | 複数種類の同時発生あり。出力は種類ごとのビット。 |
| データ | Oak Ridge National LaboratoryのLPBF層ごとの可視画像 |
| 規模 | Table 1のテスト画像26＋14＋9＋5＝54。 |
| 学習・分割 | 54件はテスト専用。異なる2機種・4条件の画像を評価。追加学習なし、文献を検索ソースとして使用。 |
| 学習方式 | ゼロショット推論、タイプ別の文献テキスト／画像RAG。 |
| 性能 | GPT-4o-mini＋RAGの平均AccuracyはAddUp Maraging Steel 0.620、EOS 17-4 PH 0.621、EOS DMREF 0.521、EOS Inconel 718 0.738。RAGなしは同順0.610/0.471/0.401/0.523（Table 3）。 |
| 比較モデル | 出現率に応じたランダム、Qwen2-VL-2B、GPT-4o-miniのRAGなし。 |
| 未知条件への評価 | 機種・材料をまたぐ推論例。各条件5–26枚と少数で、製造現場への統計的一般化は未確立。 |
| 制約 | タイプ別二値正答率のため陰性の多い種類で偏る。完全一致・macro-F1とは別。対象は工程中の粉末床の異常で完成部品の検査ではない。 |
| 確認状態 | 全文確認 |
| 図・表・構成の参照 | §2 Fig. 5、§3 Table 1、§4 Eq. 1、Table 3、Tables A1–A4 |
