# IM001：MMAD: A Comprehensive Benchmark for Multimodal Large Language Models in Industrial Anomaly Detection

Xi Jiang; Jian Li; Hanqiu Deng; Yong Liu; Bin-Bin Gao; Yifeng Zhou; Jialin Li; Chengjie Wang; Feng Zheng。2025、ICLR 2025（ベンチマーク原著）。

[IM001: MMAD: A Comprehensive Benchmark for Multimodal Large Language Models in Industrial Anomaly Detection](https://proceedings.iclr.cc/paper_files/paper/2025/hash/d91ffbe9c126765755ff52d36b715683-Abstract-Conference.html)／DOI：10.48550/arXiv.2410.09453

| 項目 | 内容 |
|---|---|
| 概要・対象 | 工業外観検査 |
| 対象製品 | MMADの対象製品・材料（電子部品、機械部品、外観素材・食品等） |
| モデル系統 | VLM（MLLM） |
| 主要モデル・処理 | 評価ベンチマーク。GPT-4o（2024-05-13）等を測定。 |
| 入力 | 実製品クエリ画像、欠陥質問と選択肢。同一製品カテゴリの正常参照画像を標準1枚添付。 |
| プロンプト | 欠陥タイプの四択。モデルごとの既定プロンプトを極力保持し、画像の複数質問は独立に実行。 |
| 出力タスク | 工業VQAの欠陥種類選択（Defect Classification） |
| 原語クラス | 製品別欠陥種類の四択。著者のデータ定義の原語キー例はzipper `split_teeth`, `squeezed_teeth`、cable `cable_swap`, `cut_inner_insulation`, `combined`。候補は質問ごとに異なる。 |
| 複合・多ラベル | 原データの `combined` ラベル例あり。VQAは原則1問1回答。 |
| データ | MMAD（MVTec AD、MVTec LOCO AD、VisA、GoodsAD由来） |
| 規模 | MMAD原版は8,366画像・39,672問。種類質問4,688問。各実験の部分集合はsplit欄。 |
| 学習・分割 | ベンチマーク評価。標準1-shotは正常画像をランダムに1枚、1-shot+は最近傍検索。単画像制約モデルでは0-shot。 |
| 学習方式 | 原ベンチマーク評価では学習しない。推論時参照を0/1/few-shot比較。 |
| 性能 | Table 2標準条件の欠陥種類Accuracy GPT-4o 65.80%、Claude-3.5-Sonnet 60.14%、Gemini-1.5-Pro 60.12%、InternVL2-76B 54.22%、AnomalyGPT-7B 27.49%。GPT-4oの74.92%は7タスク平均。 |
| 比較モデル | Gemini-1.5-Pro、Claude-3.5-Sonnet、InternVL2、AnomalyGPT、LLaVA系等。 |
| 未知条件への評価 | 複数出典・38製品カテゴリを含むが、工場／生産ラインを単位とする独立評価ではない。 |
| 制約 | 選択肢付きのVQA。比較には参照枚数や入力制約の違いがある。実ラインでの閉集合性能には読み替えない。 |
| 確認状態 | 全文確認 |
| 図・表・構成の参照 | §3、Table 1、Fig. 3、§4.1 Table 2 |
