# IM002：Detect, Classify, Act: Categorizing Industrial Anomalies with Multi-Modal Large Language Models

Sassan Mokhtar; Arian Mousakhan; Silvio Galesso; Jawad Tayyub; Thomas Brox。2025、IEEE/CVF CVPR Workshops 2025（VAND）。

[IM002: Detect, Classify, Act: Categorizing Industrial Anomalies with Multi-Modal Large Language Models](https://openaccess.thecvf.com/content/CVPR2025W/VAND/papers/Mokhtar_Detect_Classify_Act_Categorizing_Industrial_Anomalies_with_Multi-Modal_Large_Language_CVPRW_2025_paper.pdf)／DOI：10.1109/CVPRW67362.2025.00390

| 項目 | 内容 |
|---|---|
| 概要・対象 | 工業外観検査 |
| 対象製品 | カプセル、カーペット、ねじ、ファスナー、ケーブルほかMVTec/VisA製品。 |
| モデル系統 | VLM（MLLM） |
| 主要モデル・処理 | VELM（DDAD/PatchCoreとGPT-4o/4o-miniのカスケード）。異常領域を輪郭で強調しMLLMが分類。 |
| 入力 | 原画像、異常マップに基づく赤輪郭付き画像、正常参照画像。画像448×448、温度0。 |
| プロンプト | 正常品の形状、製品別欠陥クラスの定義、着目点を提示する閉集合プロンプト。 |
| 出力タスク | 画像の欠陥カテゴリ分類（閉集合・製品別クラス） |
| 原語クラス | ボトルのプロンプト例 `Broken Large`, `Broken Small`, `Contamination`（Fig. 4）。MVTec-AC再編で capsule `poke`/`crack`、carpet `cut`/`hole`、screw `thread.side`/`thread.top`、zipper `broken_teeth`/`rough` を対ごとに統合（§3.3）。 |
| 複合・多ラベル | MVTec-ACは原版のcombinedクラス4件を除外。 |
| データ | MVTec-AD、再編成MVTec-AC、再編成VisA-AC |
| 規模 | MVTec原版15製品、VisA原版12製品。VisA-ACでサンプル10件未満クラスを除外。再編後の正確な評価画像総数は未確認。 |
| 学習・分割 | 各原データセットを再編し評価。MVTec-ACは重複クラス統合・誤注記見直し・combined削除、VisA-ACは少数クラス除外・4クラス統合。 |
| 学習方式 | 正常データで学習する異常検出器。MLLM分類はプロンプトによる推論。 |
| 性能 | DDAD＋GPT-4o MVTec-AC 84.0% Accuracy、80.3% F1、79.7% κ、VisA-AC 69.6% Accuracy。GTマスクoracleはMVTec-AC 87.8%、VisA-AC 87.6%。Table 1原MVTec-ADでは81.4%だがAbstractは80.4%と記載。 |
| 比較モデル | Echo、MCAD（MVTec-AD）、PatchCore、GPT-4o-mini、oracle GTマスク。 |
| 未知条件への評価 | MVTec系とVisA系の両方で検証。異なる製品や欠陥でも適用できる一般性は評価分割に依存。 |
| 制約 | 検出器の位置精度に依存。原MVTec-ADのAccuracyはAbstractとTable 1で記載差。ベンチマークの除外・統合後の数値。 |
| 確認状態 | 全文確認 |
| 図・表・構成の参照 | §3.1–3.3、Fig. 4、§4.2 Tables 1–3 |
