| 項目 | 内容 |
|---|---|
| 概要・対象 | 電子基板外観検査 |
| 対象製品 | PCB |
| モデル系統 | 対照学習VLM由来（CLIP視覚塔のみ）＋自己教師ありViT比較 |
| 主要モデル・処理 | CLIP-ViT-B/16、DINOv2-S/14にLinear Probe、LoRA、Deep Visual Prompt Tuning（VPT）を比較。VPTでは画像ViT各層に長さ8の学習可能トークン。 |
| 入力 | DeepPCBのtested画像から正解bboxをクロップ。CLIP 224²、DINOv2 518²。参照画像・差分画像・テキスト入力は使わない。 |
| プロンプト | 視覚トークンのVPT。自然言語プロンプトや推論時のテキスト塔を用いる方式ではない。 |
| 出力タスク | 欠陥パッチ単位、単一ラベル種類分類 |
| 原語クラス | Mousebite, Open, Pinhole, Short, Spur, Spurious Copper（Table 4） |
| 複合・多ラベル | 評価単位は単一正解bbox、画像全体の複数欠陥処理は未評価。 |
| データ | DeepPCB-derived（欠陥bboxから生成） |
| 規模 | 欠陥パッチ10,013、train 6,975 / validation 1,009 / test 2,029。 |
| 学習・分割 | 欠陥種類層化7:1:2、k=5/10/20はtrainから種類ごと抽出、validation/test固定。試行3回平均の記載。基板や原画像IDでの群分けは未確認。 |
| 学習方式 | ラベル付き少数ショットおよび全データでパラメータ効率的微調整。 |
| 性能 | 全データTable 3のCLIP-VPTテストはAcc 0.990 / macro-F1 0.991 / macro-AUPRC 0.998。CLIP-Linear 0.971 / 0.972 / 0.991、CLIP-LoRA 0.969 / 0.971 / 0.992。DINOv2-VPT 0.988 / 0.988 / 0.998。少数ショットはFig. 3–4。 |
| 比較モデル | ResNet50、EfficientNet-B0、Linear Probe、LoRA、DINOv2-S/14 |
| 未知条件への評価 | 他PCBデータセットへの同プロトコル検証は今後の計画。 |
| 制約 | 既知の正解bboxによる分類であり、全基板画像からの検出・分類とは条件が異なる。Table 3のCNNはテストAcc 0.993–0.994でCLIP-VPT 0.990を上回る。 DeepPCBの元画像はPCBのCCD実撮像だが、データセット著者が試験画像に人工欠陥も手作業で追加。自然発生欠陥と追加欠陥を分けた評価は未確認。 |
