# IV003：SEM-CLIP: Precise Few-Shot Learning for Nanoscale Defect Detection in Scanning Electron Microscope Image

Qian Jin, Yuqi Jiang, Xudong Lu, Yumeng Liu, Yining Chen, Dawei Gao, Qi Sun, Cheng Zhuo。2024、IEEE/ACM ICCAD 2024。

[IV003: SEM-CLIP: Precise Few-Shot Learning for Nanoscale Defect Detection in Scanning Electron Microscope Image](https://arxiv.org/html/2502.14884)／DOI：10.1145/3676536.3676752

| 項目 | 内容 |
|---|---|
| 概要・対象 | 半導体製造外観検査 |
| 対象製品 | 12インチ55 nm CMOS製造ラインのウェハ表面 |
| モデル系統 | 対照学習VLM（テキスト枝＋視覚分類ヘッド） |
| 主要モデル・処理 | SEM-CLIP。ViT-B/16+の複数層の視覚埋め込みとテキストの類似度確率に、各層CLSから学習した分類ヘッドの確率を加重和（後者の重みα=0.8）。 |
| 入力 | 製造ラインで得たグレースケールSEM画像。クエリ画像と、全クラス共通で事前定義した候補文を比較。学習時に少数画像を使用。 |
| プロンプト | 欠陥形態の専門知識をstate-level文に入れ、SEMの暗さや焦点ずれを記述するtemplate-level文と合成。固定の候補文で全画像を評価。 |
| 出力タスク | 画像単位の単一ラベル種類分類（画素分割は別評価） |
| 原語クラス | good（非欠陥）, bridges, copper residues, holes, infilm defects, particles, scratches（§2.3の原語）。 |
| 複合・多ラベル | 未確認 |
| データ | 製造ライン取得の社内SEM画像 |
| 規模 | 1,332画像（正常226、欠陥1,106）。欠陥内訳はbridges 59、copper residues 141、holes 230、infilm defects 77、particles 455、scratches 144。 |
| 学習・分割 | 分類比較は10-shot/クラス、各モデル同一テスト。独立テスト枚数・ウェハ単位分割は本文で未確認。 |
| 学習方式 | 10-shot分類ヘッド微調整＋固定テキスト類似度。 |
| 性能 | 分類10-shotでAccuracy 83.7%、Precision 87.2%、Recall 86.7%、F1 84.4%。視覚ヘッドのみのアブレーションはAcc 83.6%/F1 84.3%、テキスト類似度のみは25.7%/16.0%。 |
| 比較モデル | ImageNet-21K事前学習のViT、ResNet101、ResNet50+ViT、EfficientNet。 |
| 未知条件への評価 | 別工場、別世代工程、未知欠陥の独立分類評価は未確認。 |
| 制約 | 単一製造ライン、クラス不均衡。テキスト併用の上積みは同アブレーションでAcc 0.1ポイント。 |
| 確認状態 | 著者版全文確認（2025年公開。会議は2024年） |
