# 調査後の監査チェックリスト

このチェックは「世界の全論文を発見した」保証ではない。検索実施範囲と残件を検証し、結論の強さを制限するために使う。

| 段階 | 確認すること | 確認資料 | 不合格時の処置 |
|---|---|---|---|
| 問い | 入力・出力・モデル・対象産業・期間・除外条件が明記されている | protocol、版履歴 | 基準変更を記録し、既存候補を再選別 |
| 検索語 | 同義語、旧称、新モデル名、出力ラベル語、異なる言語を使ったか | 検索式行列 | 未探索セルを追加検索 |
| 情報源 | 掲載誌・索引・著者版など複数経路があるか。仕様に列挙しただけではないか | search_log | 未実行・アクセス不可を区別 |
| 既知論文 | 検索式の試験用既知論文を回収できるか | known-item test | 回収できない理由を調べて検索式を修正。全世界の再現率とは呼ばない |
| 引用追跡 | 各seedの前方・後方、取得件数、全件取得か上位のみかが記録されているか | seed_checks、citation_edges | 未実施方向と未取得ページを残件化 |
| 適合性 | 出力が種類名か、程度・量・正常異常かを原文で区別したか | labels、task、locator | 本文未確認は保留。タイトルのclassificationだけで採用しない |
| 同一研究 | プレプリント・会議・雑誌版、同じデータセット系列の重複が管理されているか | candidates、DOI、dataset family | 版をまとめ、独立実証数を別集計 |
| 本文取得 | 保留候補に出版社→著者版→リポジトリ等の取得経路と結果があるか | retrieval_attempts | 403を「非公開」と呼ばない。残る手段を明記 |
| 成績 | 指標、平均方式、クラス集合、split、画像/工具/ロット単位、testかvalidationかがあるか | benchmark、claims | 未確認を埋めない。異条件をランキングしない |
| エビデンス | 数値・モデル・ラベルのClaimがSourceと本文位置までつながるか | claims、claim_evidence、sources | 孤立IDやリンクを修正。根拠がない数値は外す |
| 偏り | 産業、工具、年代、言語、モデル、データ系列の集中を説明したか | coverage matrix | 未調査と調査済未発見を区別 |
| 終了 | 新規適合数の推移、残る候補と未探索経路を示したか | round report、frontier | 新規が出る間は飽和と宣言しない |

`python scripts/audit_literature_search.py` はID・記録項目・追跡の不足を機械的に点検する。論文内容の適合性、数値の転記、出版社本文と索引の相違は人またはエージェントが原資料で確認する。自動チェックのPASSと網羅性の十分さは別の判定である。

独立レビューを行える場合は、採用全件と、無作為に選んだ除外候補を第二査読者が再判定し、不一致を解決する。今回の担当分担は独立二重スクリーニングではない。抽出割合と抽出乱数・対象IDを記録するまで「除外監査済み」としない。
