# 現在までの探し方と、その限界

対象：2026-11-11の工具摩耗種類分類15行・工業欠陥種類分類38行を作成した時点。今回の引用追跡ラウンド2とは分けた記録である。

## 実際に行った流れ

1. 入力画像、対象製品、出力ラベルを定義した。工具ではflank/chipping/BUE等、工業ではdefect type/classification、モデルではViT/CLIP/VLM等を組み合わせてWeb横断検索した。
2. 工具の既存59本を新しい種類分類条件で再選別した。工業側はモデル系統で分担し、鋼材、SEM、PCB、ウェハ、太陽電池等の語を追加した。
3. 検索結果から出版社、会議公式、著者公開版、機関リポジトリへ移り、ラベル、推論入力、分類指標、実際の数値、評価条件を確認した。
4. 本文が取れない場合は著者版、公開抄録、検索経由の本文抜粋等を使い、確認範囲を区別した。関連研究・保留・対象外を分離した。
5. 原著で見つかった関連文献を一部追跡したが、全seedの全参考文献・被引用論文を列挙して採否を付ける運用ではなかった。
6. DOI・題名の重複、Source/Claimの対応、評価条件の不一致を確認し、比較表と精度一覧へまとめた。

ログ行には複数クエリのバッチや直接取得が混ざるため、106種類の独立した検索式を実行したという意味ではない。元の[工具ログ](../evidence/wear_type_classification/search_log.csv)と[工業ログ](../evidence/industrial_defect_classification/search_log.csv)を残し、不足した時刻・取得件数を今回推測して埋め直していない。

調査仕様にGoogle Scholar、Crossref、OpenAlex、IEEE Xplore等を列挙したことと、その各データベースで検索集合を全件取得したことは別である。従来ログでは、OpenAlex等の引用グラフをページ末尾まで取得した記録はない。Google Scholar等の独立した検索集合を完全に輸出して比較したという主張もできない。

## 何ができていて、何が足りなかったか

対象タスクの厳密な選別、モデルと入力の区別、原著数値と条件の追跡、未確認の表示は実施できていた。一方、検索式ごとの候補集合、全引用の採否、研究分野別の検索枠、探索の繰り返しによる追加発見数は十分に構造化されていなかった。

そのため、代表方式を比較する資料として使えても、取りこぼしが少ないことや探索終了の妥当性を第三者が検証する材料は不足していた。ラウンド2では候補・引用edge・本文取得試行・seed方向別の進捗を加えた。新しい記録方式によって、過去の未記録分まで検証済みになるわけではない。

## Round2で追加した実際の手順

主要16本の前方・後方の32方向を確認し、OpenAlex/Crossrefの引用メタデータと原著参考文献、DOI・題名検索を組み合わせた。Wu2019ではOpenAlexから後方31件・基準日付き前方160件を取得し、全タイトルと利用できた抄録を一次選別した。ほかには全件取得できた索引集合と、上位検索・選択文献の部分確認が混在する。

検索・確認128行、候補発見279行、引用・関連・異版276行、取得試行76行を追記し、DOI・正規化題名による候補対応表を作成した。これらの行数は独立論文数ではない。現在の範囲は[方向別台帳](../evidence/round2/seed_coverage.csv)と[監査](../reports/search_process_audit.md)、追加結果は[Round2報告](../reports/round2_findings.md)に示す。

全件引用追跡を全論文へ再帰適用したわけではなく、Google Scholar／IEEE／J-STAGE／CiNiiの各DB内で全検索集合を独立取得したわけでもない。これらは次回の残件として明記している。
